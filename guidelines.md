# HuliCAP Community & Security Guidelines

Welcome to the HuliCAP Insider Threat Monitoring platform. To safeguard organizational privacy and maintain secure multi-tenant boundaries, all users and organizations must adhere to these guidelines.

## Quick TL;DR Guidelines

1. **Synthetic Data Only:** Use synthetic or approved test data only.
2. **Zero Real Personal Data:** No real personal data.
3. **Metadata Only:** Don't upload file contents.
4. **Cross-Tenant Isolation:** Don't attempt to access other organizations' data.
5. **Platform Usage Limits:** Adhere to the platform limits (up to 100,000 events per upload and up to 20 staff seats).
6. **Account Suspension Policy:** Accounts that break these rules can be suspended.
